# Butterfly 2.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a separate Butterfly 2.0 experiment whose landing on an index fingertip transforms the live webcam into a detailed green ASCII portrait through a radial wave.

**Architecture:** Keep all new behavior in `src/experiments/butterfly-2/`. Pure geometry and image-processing modules provide testable data; `Experiment.tsx` owns MediaPipe, animation state, audio, and Canvas 2D composition. The original Butterfly remains unchanged.

**Tech Stack:** React 19, TypeScript 6, Canvas 2D, MediaPipe Hand Landmarker, Vitest, existing animation/webcam/audio hooks.

## Global Constraints

- The existing `/e/butterfly` route and committed source must remain unchanged.
- The new route and metadata slug are `/e/butterfly-2` and `butterfly-2`.
- Add no dependency and do not modify shared modules.
- The ASCII view is live green glyphs on true black, not a frozen frame.
- ASCII is active only while the butterfly is perched; takeoff reverses the wave.
- The butterfly stays light grey/white above the green portrait.
- Respect `paused`, Canvas DPR handling, recorder compatibility, and unmount cleanup.
- Avoid per-frame arrays and full-resolution `getImageData`.

- [ ] **Step 3: Implement bounded pure helpers**

Create `asciiPortrait.ts` with:

```ts
export const ASCII_RAMP = ' .,:;irsXA253hMHGS#9B&@'

const clamp01 = (value: number) => Math.max(0, Math.min(1, value))

export function computeLuminance(data: Uint8ClampedArray, out: Float32Array) {
  for (let source = 0, target = 0; target < out.length; source += 4, target++) {
    out[target] = 0.2126 * data[source] + 0.7152 * data[source + 1] + 0.0722 * data[source + 2]
  }
}

export function normalizeLuminance(value: number, black = 18, white = 225) {
  return clamp01((value - black) / Math.max(1, white - black)) ** 0.78
}

export function edgeStrength(
  luma: Float32Array,
  x: number,
  y: number,
  width: number,
  height: number,
) {
  if (x <= 0 || y <= 0 || x >= width - 1 || y >= height - 1) return 0
  const at = (dx: number, dy: number) => luma[(y + dy) * width + x + dx]
  const gx = -at(-1, -1) + at(1, -1) - 2 * at(-1, 0) + 2 * at(1, 0) - at(-1, 1) + at(1, 1)
  const gy = -at(-1, -1) - 2 * at(0, -1) - at(1, -1) + at(-1, 1) + 2 * at(0, 1) + at(1, 1)
  return clamp01(Math.hypot(gx, gy) / 1020)
}

export function glyphIndex(value: number, edge: number, rampLength: number) {
  return Math.round(clamp01(value + Math.min(0.28, edge * 0.24)) * (rampLength - 1))
}

export function waveCoverage(
  x: number,
  y: number,
  originX: number,
  originY: number,
  radius: number,
  feather = 80,
) {
  return clamp01((radius + feather / 2 - Math.hypot(x - originX, y - originY)) / feather)
}

export function maxCornerDistance(originX: number, originY: number, width: number, height: number) {
  return Math.max(
    Math.hypot(originX, originY),
    Math.hypot(width - originX, originY),
    Math.hypot(originX, height - originY),
    Math.hypot(width - originX, height - originY),
  )
}
```

- [ ] **Step 2: Add the live portrait sampler**

Use cell dimensions near `7×12`, request
`getContext('2d', { willReadFrequently: true })`, mirror the video into a
`cols×rows` offscreen canvas, and call `getImageData` only on that grid.

For every cell:

- normalize luminance;
- compute edge strength;
- choose a glyph;
- skip cells below the calibrated visibility threshold;
- use `waveCoverage` at the cell center;
- draw black cell backing with coverage;
- draw the glyph in luminance-scaled phosphor green with coverage.

Use batched style values from a small fixed green palette to avoid generating a
new CSS color string for every cell.

1. draw the mirrored photographic webcam;
2. if wave radius is positive, draw ASCII cells over it;
3. each ASCII cell paints its own opaque black cell background according to

4. after the portrait, draw fingertip feedback and the light butterfly.

The resulting fully covered frame must have no photographic pixels visible.

- [ ] **Step 2: Implement transition radius**

Use an ease-in-out cubic:

```ts
export type TransitionMode = 'revealing' | 'hiding'

export function transitionRadius(
  mode: TransitionMode,
  elapsed: number,
  duration: number,
  maxRadius: number,
) {
  const t = Math.max(0, Math.min(1, elapsed / duration))
  const eased = t < 0.5 ? 4 * t * t * t : 1 - ((-2 * t + 2) ** 3) / 2
  return maxRadius * (mode === 'revealing' ? eased : 1 - eased)
}
```

- [ ] **Step 3: Connect landing and takeoff transitions**

Detect the existing `perched` state edge:

- `false → true`: store current nearest fingertip in `waveRef`, set
  `mode='revealing'`, and set `startedAt=now`;
- when revealing reaches 700 ms: set `mode='ascii'`;
- `true → false`: keep the stored origin, set `mode='hiding'`, and set
  `startedAt=now`;
- when hiding reaches 700 ms: set `mode='photo'` and radius zero.

Do not reverse `hiding` merely because a hand is reacquired. A new landing is
required.
